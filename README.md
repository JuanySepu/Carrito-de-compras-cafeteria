# Carrito-de-compras-cafeteria
Proyecto final del curso de Javascript de Coder House.

Se creó este sitio como proyecto final del curso de Javascript de Coder House. Donde se aplicaron los principales conceptos aprendidos durante la cursada.

Éste sitio recrea un carrito de compras de una cefetería, mostrando los productos con su clasificación, descripción y precio. Al seleccionar un producto con el botón se agrega al carrito que se encuentra sobre el lado derecho, pudiendo agregar otros productos o mayor cantidad del mismo, reducir la cantidad del producto seleccionado o inclusive eliminar un producto del carrito.
Al darle al botón "Realizar Pedido" aparece un modal donde te muestra un resumen del pedido realizado y la confirmación del mismo. Con un botón para poder seguir comprando, el cual reinicia el sitio.
